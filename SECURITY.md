# Security Policy

Nếu phát hiện lỗi có thể làm lộ file, truy cập sai đường dẫn hoặc cho phép trang web khác tương tác với API nội bộ, **đừng công bố chi tiết trong Issue công khai**. Hãy sử dụng chức năng **Report a vulnerability** (GitHub Private Vulnerability Reporting) của repository nếu được bật, hoặc liên hệ trực tiếp chủ dự án bằng kênh riêng đã công bố.

Không gửi khóa, mật khẩu, log hoặc tệp riêng tư cùng báo cáo.
